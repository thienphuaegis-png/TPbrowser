🔌 TPbrowser Built-in MCP Server (Model Context Protocol)

ĐANG CHẠY TRỰC TIẾP (Cổng 17777)

Danh Sách 15 Công Cụ MCP (Tools) JSON-RPC 2.0

1. tp_list_tabs
Liệt kê tất cả tab đang mở (ID, Title, URL, tab đang active, chế độ xem).
2. tp_get_page_context
Đọc cấu trúc DOM, tiêu đề, URL, text và ID các nút bấm trên trang để AI phân tích.
target: active/zalo/fbmax_chars: 9000
3. tp_execute_action
Thực hiện hành động click chuột, gõ phím, cuộn trang hoặc điều hướng URL.
type: click/fill/scrolltarget_idvalue
4. tp_eval_js
Chạy lệnh JavaScript bất kỳ trực tiếp trên WebView và trả về kết quả JSON.
code (JS string)target: active/zalo/fb
5. tp_open_tab & tp_close_tab
Mở tab mới (hỗ trợ Isolated Profile riêng biệt) hoặc đóng tab theo ID.
urlisolated: bool
6. tp_focus_tab & tp_navigate
Chuyển đổi tab đang xem hoặc điều hướng back/forward/reload.
7. tp_chat_open, tp_chat_scan, tp_chat_draft
Quét tin nhắn Zalo Web / Facebook Messenger và điền sẵn tin nhắn nháp cho anh duyệt.
channel: zalo/fbtext: draft
8. tp_tasks_list, tp_task_complete, tp_task_snooze
Đọc, lưu và đánh dấu hoàn thành danh sách công việc/nhắc nhở nội bộ.

Cách Kết Nối Vào Claude Desktop / Hermes Agent / AI

TPbrowser tích hợp sẵn MCP Server 2 trong 1: HTTP Endpoint và Stdio CLI Bridge.

1. Cấu hình cho Claude Desktop (claude_desktop_config.json):
{
  "mcpServers": {
    "tpbrowser": {
      "command": "D:\\Projects_Hermes\\TPbrowser\\target\\release\\TPbrowser.exe",
      "args": ["--mcp"]
    }
  }
}
2. Gọi kiểm tra trực tiếp qua Terminal (cURL HTTP):
# 1. Kiểm tra liveness & số tab đang mở:
curl http://127.0.0.1:17777/health

# 2. Lấy danh sách 15 Tools của TPbrowser:
curl -X POST http://127.0.0.1:17777/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
3. Dữ liệu Tài nguyên (Resources):
• tpbrowser://tabs: Danh sách tab theo thời gian thực.
• tpbrowser://tasks: Việc cần làm trong Cowork.
• tpbrowser://skills: Kỹ năng tự động hóa đã ghi lại.
